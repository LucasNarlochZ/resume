# Projects

## Sunlog.dev

Production full stack devlog platform that helps developers document projects, technical decisions, and development progress. It has a Next.js frontend and a NestJS REST backend with 33 HTTP endpoints, PostgreSQL persistence, JWT authentication, asynchronous processing, and more than 100 automated tests. The platform is deployed on automated AWS infrastructure using Docker, Nginx, and GitHub Actions, with structured logging and observability through Prometheus and Grafana.

**Technologies:** Next.js, NestJS, TypeScript, PostgreSQL, JWT, REST APIs, Docker, Nginx, AWS, GitHub Actions, Prometheus, Grafana

- **Code:** https://github.com/LucasNarlochZ/Sunlog.dev
- **Live demo:** https://sunlog.dev

## PocScript

Programming language and compiler implemented in C, covering the complete compilation pipeline: lexical analysis, AST parsing, semantic analysis, custom intermediate representation generation, LLVM IR emission, and native executable generation. It includes a custom runtime based on Linux system calls, a static type system, scope resolution, arrays, pointers, memory concepts, error handling, and 196 unit and integration tests.

**Technologies:** C, LLVM IR, NASM, Make, Linux system calls, Compiler Design

- **Code:** https://github.com/LucasNarlochZ/PocScript

## PCBuilderBR

Full stack application for selecting computer components, with a React interface and a FastAPI and PostgreSQL backend. Its REST APIs calculate prices and analyze compatibility among CPUs, motherboards, RAM, GPUs, power supplies, coolers, and cases. A rule engine validates sockets, chipsets, DDR generations, TDP, connectors, and dimensions, while a daily worker automatically updates prices across multiple e-commerce stores.

**Technologies:** React, Vite, Tailwind CSS, Axios, FastAPI, PostgreSQL, REST APIs, Docker

- **Code:** https://github.com/LucasNarlochZ/PCBuilderBR
- **Live demo:** https://pcbuilderbr.com
